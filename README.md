# Conecta ONG — Associação Amor e Ação de Cotia

MVP desenvolvido para otimizar o atendimento presencial de triagem e o controlo de estoque social, alinhado à Meta 1.3 do **ODS 1 (Erradicação da Pobreza)**.

## 🚀 Requisitos e Funcionalidades
- **RF-01:** Autenticação e gestão de acesso restrito de voluntários.
- **RF-02:** Consulta e baixa em tempo real de itens do estoque social.
- **RF-03:** Registo rápido de atendimento presencial por CPF.
- **RTA-01:** Diretrizes de acessibilidade (áreas de toque $\ge 44\text{px}$, contraste mínimo 4.5:1 e alertas multimodais).

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript
- Git & GitHub (Conventional Commits)

## 📌 Como Executar o Projecto
1. Clona este repositório: `git clone https://github.com/seu-usuario/conecta-ong-amor-acao-cotia.git`
2. Abre o ficheiro `index.html` no teu navegador.
